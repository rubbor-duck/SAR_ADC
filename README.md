This is my final project for my Digital Systems Design class. My partner and I created an 8-bit SAR ADC using a Baysis 3 FPGA board and a DAC. 
We also created a 2-bit FLASH ADC. In this repository, I have included the final report for both ADC's and the SystemVerilog project files.
I was the main designer of the SAR ADC, while my partner was the main designer of the FLASH ADC. I have only included the SAR ADC files in this repository.
You can find the modules for the SAR by going to "SAR_ADC/SAR_ADC.srcs/sources_1/new".
